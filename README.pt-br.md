<h1>Galeria de Fotos Com JQuery</h1>
<p>
    This README is also available in <a href="./README.md">English</a>.
</p>
<p>
    Uma galeria de fotos dinâmica construída com
    <strong>HTML5</strong>, <strong>CSS3</strong>,
    <strong>JavaScript</strong> e <strong>jQuery</strong>.
    Permite adicionar novas imagens via link, com animações de slide e fade.
    O layout da galeria se ajusta ao tamanho da tela, mas não é totalmente otimizado para mobile.
</p>
<p>
    🔗 Live Demo: <a href="https://photo-gallery-with-jquery-asrdrgm.vercel.app/" target="_blank">Ver na Vercel</a>
</p>
<h2>Sobre</h2>
<p>
    Este projeto simula uma galeria de fotos interativa.
    O usuário pode abrir o formulário para inserir links de imagens, que são adicionadas dinamicamente à galeria.
    Cada foto possui uma sobreposição com link para visualização em tamanho real.
</p>
<h2>Tecnologias Utilizadas</h2>
<ul>
    <li>HTML5</li>
    <li>CSS3 (ajustes básicos de responsividade)</li>
    <li>JavaScript</li>
    <li>jQuery (manipulação de DOM, formulários e animações)</li>
</ul>
<h2>Funcionalidades</h2>
<ul>
    <li>Adicionar novas imagens à galeria via URL;</li>
    <li>Exibir/esconder formulário com animações de slide;</li>
    <li>Efeito de fade-in ao inserir novas fotos;</li>
    <li>Sobreposição com link para ver a imagem em tamanho real;</li>
    <li>Layout em grid responsivo.</li>
</ul>
<h2>Notas</h2>
<p>
    Este projeto foi desenvolvido como prática de manipulação de DOM com jQuery e efeitos em CSS.
    Apesar de se ajustar a diferentes tamanhos de tela, o design é simples e não foi pensado para uso em dispositivos móveis.
</p>
