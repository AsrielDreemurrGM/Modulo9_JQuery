<h1>Photo Gallery With JQuery</h1>
<p>
    Este README também está disponível em <a href="./README.pt-br.md">Português</a>.
</p>
<p>
    A dynamic photo gallery built with
    <strong>HTML5</strong>, <strong>CSS3</strong>,
    <strong>JavaScript</strong>, and <strong>jQuery</strong>.
    Users can add new images via link, with smooth slide and fade animations.
    The gallery layout adjusts to screen size but is not fully styled for mobile.
</p>
<p>
    🔗 Live Demo: <a href="https://photo-gallery-with-jquery-asrdrgm.vercel.app/" target="_blank">View on Vercel</a>
</p>
<h2>About</h2>
<p>
    This project simulates an interactive photo gallery.
    Users can open the form to insert new image links, which are added dynamically to the gallery.
    Each photo includes an overlay with a link to view it in full size.
</p>
<h2>Technologies Used</h2>
<ul>
    <li>HTML5</li>
    <li>CSS3 (basic responsive adjustments)</li>
    <li>JavaScript</li>
    <li>jQuery (form handling, animations, DOM manipulation)</li>
</ul>
<h2>Features</h2>
<ul>
    <li>Add new images to the gallery via URL;</li>
    <li>Show/hide form with slide animations;</li>
    <li>Fade-in effect when new photos are added;</li>
    <li>Overlay with link to view the image in real size;</li>
    <li>Responsive grid layout.</li>
</ul>
<h2>Notes</h2>
<p>
    This project was developed as practice for DOM manipulation with jQuery and CSS effects.
    While the gallery adjusts to screen sizes, its design is simple and not optimized for mobile devices.
</p>
